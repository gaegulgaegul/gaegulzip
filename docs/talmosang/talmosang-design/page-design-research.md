# Page Design Research: 캐릭터 & 인터랙티브 효과

> 탈모상 앱의 사용자 참여도 및 경험 향상을 위한 캐릭터/효과 리서치

## 현재 디자인 분석

### 스타일 컨셉
- **비주얼**: Al Murphy 영감 — 노란 배경(#ffe847), 굵은 검정 테두리(8px), 하드 그림자(offset shadow)
- **톤앤매너**: 사극 관상가 — 고어체 말투, 한지/두루마리 느낌
- **타이포**: Black Han Sans(타이틀), Jua(서브), Pretendard(본문)
- **색상 팔레트**: 노랑(#ffe847), 핑크(#ff69b4), 빨강(#ff4444), 초록(#00cc66), 검정(#1a1a1a)

### 현재 인터랙션
| 인터랙션 | 위치 | 방식 |
|----------|------|------|
| hover 확대/회전 | 업로드 카드, 버튼 | CSS transform |
| 드래그앤드롭 | 업로드 존 | React state + CSS |
| 머리카락 낙하 | 로딩 화면 | CSS keyframe |
| 카운트업 숫자 | 결과 화면 | requestAnimationFrame |
| shake/wiggle | 버튼 hover | CSS keyframe |

### 부족한 점
- 캐릭터 부재로 감정적 연결/스토리텔링 약함
- 스크롤 인터랙션 없음 (단일 뷰포트 중심)
- 결과 전환이 즉시 렌더링 (극적 효과 없음)
- 페이지가 정적인 느낌 — 바이럴 공유 유인 부족

## 선택된 캐릭터 (4종)

### 스타일 가이드 (공통)

```
Style: Flat vector, geometric simplified shapes
Colors: 앱 기존 팔레트 활용 (노랑, 빨강, 초록, 검정, 흰색)
Outline: 검정 3-4px stroke (Al Murphy 스타일과 통일)
Format: SVG (인라인) — GSAP 애니메이션 호환
Size: 120-200px (데스크탑), 80-120px (모바일)
Animation: CSS + GSAP (hover, scroll trigger)
```

### 1. 사극 관상가 영감 (메인 가이드)

**외형 사양:**
- 머리: 갓(검정 #1a1a1a), 둥근 얼굴(살구색 #FFD5B5)
- 표정: 둥근 눈(•ᴗ•), 길고 흰 수염 3가닥
- 몸: 도포(하늘색 #87CEEB), 넓은 소매
- 소품: 돋보기(노랑 #ffe847 테두리)
- 포즈: 돋보기 들고 들여다보는 자세

**등장 위치:**
| 화면 | 위치 | 상태 | 애니메이션 |
|------|------|------|-----------|
| 업로드 전 | 헤더 옆 우측 | 기본 포즈 (돋보기 들고 대기) | idle: 수염 흔들림, 눈 깜빡 |
| 업로드 후 | 미리보기 옆 | 돋보기로 사진 살피는 포즈 | 돋보기 좌우 이동 |
| 로딩 중 | 프로그레스 바 위 | 집중하는 표정 | 수염 만지기 + 고개 끄덕 |
| 결과 좋음 | 결과 카드 좌측 | 미소 + 엄지척 | bounce + rotate |
| 결과 나쁨 | 결과 카드 좌측 | 걱정 표정 + 부채질 | shake head |

**대사 풀 (클릭 시 랜덤):**
```
- "허허, 어디 한번 살펴보겠소이다"
- "오호라, 이 관상이 범상치 않구려"
- "두피의 기운이 묘하게 흐르고 있사옵니다"
- "관상은 팔자를 이기는 법이오"
- "모발의 운명은 관리에 달렸사옵니다"
```

### 2. 머리카락 요정 삼총사

**외형 사양:**
각 캐릭터는 머리카락 한 올을 의인화한 미니 캐릭터

| 요정 | 색상 | 표정 | 의미 |
|------|------|------|------|
| **건강이** | 초록(#00cc66) | 활짝 웃음 (◕ᴗ◕) | 등급 A — 건강한 모발 |
| **보통이** | 노랑(#ffe847) | 보통 표정 (•_•) | 등급 B-C — 보통 상태 |
| **위험이** | 빨강(#ff4444) | 걱정 표정 (•̥﹏•̥) | 등급 D — 위험 상태 |

**공통 특징:**
- 몸통: 길쭉한 곡선 (머리카락 형태)
- 팔다리: 짧고 둥근 stub
- 크기: 60-80px

**등장 위치:**
| 화면 | 등장 조건 | 역할 |
|------|----------|------|
| 결과 등급 원 주변 | 등급에 따라 해당 요정 | 등급 시각적 강화 |
| 확률 프로그레스 바 | 바 위에서 달리기 | 진행 상황 표현 |
| 관리 팁 항목 | 각 팁 아이콘 대체 | 정보 전달 보조 |

### 3. 두피 수호신 장군

**외형 사양:**
- 머리: 투구(검정, 깃털 장식 빨강)
- 몸: 갑옷(초록 #00cc66), 방패(노랑 #ffe847)
- 표정: 든든한 미소 + 결연한 눈빛
- 소품: 방패에 "守" 글자 or 모낭 아이콘
- 크기: 100-120px

**등장 위치:**
| 화면 | 위치 | 역할 |
|------|------|------|
| 안심 문구 옆 | DisclaimerText 좌측 | "사진 소각" 안심감 강화 |
| 관리 팁 섹션 헤더 | 팁 리스트 상단 | "모발을 지키는 법" 가이드 |
| 공유 버튼 옆 | 결과 하단 | "관상을 널리 알리시오" 유도 |

### 4. 탈모 도깨비

**외형 사양:**
- 머리: 뿔 2개 (빨강 #ff4444), 대머리
- 몸: 호피무늬(노랑+검정), 방망이 대신 가위
- 표정: 장난스러운 미소 (ψ(｀∇´)ψ)
- 소품: 가위(빨강), 빼앗은 머리카락 다발
- 크기: 100-120px

**등장 위치:**
| 화면 | 조건 | 역할 |
|------|------|------|
| 로딩 화면 | 항상 | 머리카락 낙하와 함께 가위질 모션 |
| 결과 D등급 | 확률 60%+ | 가위를 흔들며 위협하는 포즈 |
| 결과 A등급 | 확률 30%- | 도망가는 포즈 (수호신에게 쫓김) |

**캐릭터 상호작용:**
- 도깨비 ↔ 수호신: 결과 좋으면 수호신이 도깨비를 쫓아냄
- 도깨비 ↔ 요정: 도깨비가 요정을 쫓으면 요정이 도망
- 관상가 ↔ 도깨비: 관상가가 부적으로 도깨비 봉인

## 선택된 인터랙티브 효과 (2종)

### 1. 스크롤 패럴랙스

**구현 방식:** GSAP ScrollTrigger

**레이어 구조:**
```
Layer 0 (배경):  노랑 배경 — 고정
Layer 1 (원경):  구름/산 실루엣 — 0.2x 속도
Layer 2 (중경):  캐릭터들 — 0.5x 속도, 특정 지점에서 등장/대사
Layer 3 (근경):  메인 콘텐츠 — 1x 속도 (기본)
Layer 4 (전경):  장식 요소 (별, 머리카락) — 1.3x 속도
```

**스크롤 이벤트 시퀀스:**

| 스크롤 % | 이벤트 | 캐릭터 | 효과 |
|----------|--------|--------|------|
| 0-10% | 페이지 진입 | 관상가 등장 | 좌측에서 슬라이드 인 |
| 10-30% | 업로드 섹션 | 관상가 돋보기 들어올림 | 말풍선 "어디 한번 보겠소" |
| 30-50% | 업로드 존 접근 | 도깨비 우측에서 peek | 살짝 얼굴만 보이다 숨기 |
| 50-70% | 분석 유도 | 수호신 등장 | 방패 들고 안심 표시 |
| 70-100% | 푸터 접근 | 요정 삼총사 인사 | 손 흔들며 퇴장 |

**모바일 대응:**
- 패럴랙스 속도 50% 감소 (모션 부담 줄임)
- `prefers-reduced-motion: reduce` 시 패럴랙스 비활성화
- 캐릭터 크기 60-80% 축소

**기술 스택:**
```
- GSAP 3.x + ScrollTrigger plugin
- 또는 Framer Motion (React 네이티브)
- IntersectionObserver (폴백)
```

### 2. 결과 극적 리빌

**구현 방식:** GSAP Timeline + CSS 파티클

**리빌 시퀀스 (3초):**

```
T+0.0s: 화면 암전 (검정 오버레이 fade-in)
T+0.3s: 두루마리 SVG 상단에서 펼쳐짐 (scaleY: 0→1)
T+0.5s: "관상 결과가 나왔사옵니다!" 텍스트 stamp 효과 (scale: 2→1 + rotation)
T+1.0s: 등급 원형 뱃지 — 중앙에서 bounce-in
T+1.2s: 관상가 캐릭터 — 등급에 따른 리액션 등장
T+1.5s: 오버레이 fade-out, 실제 결과 카드 순차 공개

등급별 파티클 효과:
- A등급: 금색 별 + 폭죽 파티클 ✨ + 초록 요정 춤
- B등급: 은색 별 + 가벼운 반짝임 + 노랑 요정 고개 끄덕
- C등급: 노랑 나뭇잎 흩날림 + 관상가 걱정 표정
- D등급: 머리카락 폭포 낙하 🪮 + 도깨비 등장 + 빨강 요정 울상
```

**카드 순차 공개 (stagger):**
```
1. 등급 원형 뱃지 (0ms)
2. 모발 나이 카드 (200ms)
3. 5년 탈모 확률 (400ms)
4. 탈모 유형 (600ms)
5. 닮은 유명인 (800ms)
6. 관리 팁 (1000ms)
7. 종합 코멘트 (1200ms)
```

**기술 스택:**
```
- GSAP Timeline (시퀀스 제어)
- CSS @keyframes (파티클)
- Canvas API 또는 tsParticles (고급 파티클)
```

## 기술 의존성

| 라이브러리 | 용도 | 번들 크기 |
|-----------|------|----------|
| **gsap** | 스크롤 패럴랙스 + 리빌 시퀀스 | ~30KB gzip |
| **@gsap/react** | React 통합 | ~3KB gzip |
| **ScrollTrigger** (GSAP plugin) | 스크롤 기반 트리거 | GSAP에 포함 |

**SVG 캐릭터 관리:**
- `components/characters/` 디렉토리에 각 캐릭터 SVG 컴포넌트
- 각 캐릭터 파츠를 별도 `<g>` 그룹으로 분리 (GSAP 개별 제어용)
- `ref`를 통해 GSAP에서 파츠별 애니메이션 접근

## 구현 우선순위

```
Phase 1: 캐릭터 SVG 제작 (관상가 → 도깨비 → 수호신 → 요정)
Phase 2: 결과 극적 리빌 효과 (GSAP Timeline)
Phase 3: 스크롤 패럴랙스 (GSAP ScrollTrigger)
Phase 4: 캐릭터 인터랙션 (클릭 대사, 상호작용)
Phase 5: 모바일 최적화 + 접근성
```
