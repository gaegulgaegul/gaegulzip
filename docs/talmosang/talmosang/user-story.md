# 사용자 스토리: 탈모상

## 개요

"탈모상"은 사용자가 사진을 업로드하면 AI가 두피 상태를 재미있게 분석하고, 10년 뒤 예상 헤어라인 시뮬레이션 이미지를 제공하는 바이럴 웹앱입니다. 영화 "관상"의 명대사 "내가 왕이 될 상인가?"를 패러디한 "내가 탈모가 될 상인가?"를 핵심 훅으로 사용하여 100% 재미 목적의 콘텐츠를 제공합니다.

**핵심 가치**: 사용자가 짧은 시간 내에 재미있는 결과를 얻고 즉시 공유할 수 있는 가벼운 경험을 제공하여 바이럴 확산을 유도합니다. 의료 진단이 아닌 엔터테인먼트 콘텐츠임을 명확히 합니다.

---

## 사용자 페르소나

### 1. 재미를 찾는 사용자 (Primary)
- **특징**: 20-40대, SNS 활동이 활발하며 트렌디한 콘텐츠에 관심이 많음
- **니즈**: 친구들과 공유할 재미있는 콘텐츠를 빠르게 찾고 싶음
- **행동**: 사진 업로드 → 결과 확인 → SNS 공유

### 2. 탈모 고민 사용자 (Secondary)
- **특징**: 실제 탈모 고민이 있으나 가벼운 접근을 원함
- **니즈**: 진지한 진단보다는 재미있는 방식으로 자신의 상태를 확인하고 싶음
- **행동**: 결과의 관리팁과 유명인 비교에 관심

## 사용자 스토리

### US-1: 사진 업로드
- **As a** 사용자
- **I want to** 드래그앤드롭이나 카메라로 손쉽게 내 사진을 업로드할 수 있다
- **So that** 복잡한 절차 없이 빠르게 분석을 시작할 수 있다

### US-2: 사진 미리보기 및 재촬영
- **As a** 사용자
- **I want to** 업로드한 사진을 미리보고, 마음에 들지 않으면 다시 업로드할 수 있다
- **So that** 원하는 사진으로 정확한 분석을 받을 수 있다

### US-3: AI 두피 분석
- **As a** 사용자
- **I want to** 업로드한 사진을 기반으로 AI가 내 두피 상태를 재미있게 분석해준다
- **So that** 모발 등급, 모발 나이, 탈모 확률, 탈모 유형 등을 한눈에 확인할 수 있다

### US-4: 10년 뒤 헤어라인 시뮬레이션
- **As a** 사용자
- **I want to** AI가 생성한 10년 뒤 내 예상 헤어라인 이미지를 볼 수 있다
- **So that** 미래의 모습을 재미있게 상상하고 친구들과 공유할 수 있다

### US-5: 닮은 유명인 비교
- **As a** 사용자
- **I want to** 내 두피/헤어 상태와 유사한 유명인을 추천받는다
- **So that** 더 친근하고 재미있게 결과를 받아들일 수 있다

### US-6: 관리팁 제공
- **As a** 사용자
- **I want to** 내 두피 상태에 맞는 간단한 관리팁을 받는다
- **So that** 재미와 함께 실용적인 정보도 얻을 수 있다

### US-7: 결과 공유
- **As a** 사용자
- **I want to** 분석 결과 카드와 시뮬레이션 이미지를 SNS에 즉시 공유할 수 있다
- **So that** 친구들과 재미있는 콘텐츠를 빠르게 나눌 수 있다

### US-8: 분석 과정 실시간 피드백
- **As a** 사용자
- **I want to** AI 분석 중에 사극 말투의 재미있는 로딩 메시지를 본다
- **So that** 대기 시간이 지루하지 않고 몰입감 있게 경험할 수 있다

### US-9: 광고 노출 수용
- **As a** 사용자
- **I want to** 무료 서비스를 이용하는 대신 적절한 위치에 광고를 본다
- **So that** 서비스가 지속 가능하게 운영되도록 기여할 수 있다

### US-10: 모바일 최적화 경험
- **As a** 모바일 사용자
- **I want to** 모바일 브라우저에서도 데스크톱과 동일한 품질로 사진 촬영 및 업로드할 수 있다
- **So that** 언제 어디서나 편리하게 서비스를 이용할 수 있다

## 사용자 시나리오

### 시나리오 1: 첫 방문 사용자의 정상 플로우

1. 사용자가 친구에게 공유받은 링크를 통해 탈모상 웹앱에 접속한다
2. 시스템이 메인 화면을 표시한다
   - 큰 타이틀: "탈모상"
   - 메인 카피: "이보시오 관상가 양반, 내가 탈모가 될 상인가?"
   - 사진 업로드 영역 (드래그앤드롭 또는 클릭하여 업로드)
3. 사용자가 스마트폰으로 셀카를 찍거나 기존 사진을 선택한다
4. 시스템이 업로드된 사진 미리보기를 표시하고 "분석 시작" 버튼을 활성화한다
5. 사용자가 "분석 시작" 버튼을 누른다
6. 시스템이 분석 중 로딩 화면을 표시한다
   - 사극 말투 메시지가 5-10초마다 전환됨
   - 예: "두피를 살펴보고 있사옵니다...", "모발의 운명을 점치고 있사옵니다..."
7. 20-30초 후, 시스템이 결과 화면을 표시한다
   - **분석 결과 카드**:
     - 모발 등급 (예: "A등급 - 탄탄한 모발")
     - 모발 나이 (예: "실제 나이보다 5살 젊음")
     - 탈모 확률 (예: "35%")
     - 탈모 유형 (예: "M자형 초기 단계")
     - 닮은 유명인 (예: "송중기 초기 헤어라인")
     - 관리팁 (3-5개 항목)
   - **10년 뒤 시뮬레이션 이미지** (AI 생성)
8. 사용자가 결과를 확인하고 "공유하기" 버튼을 누른다
9. 시스템이 Web Share API를 실행하여 SNS 공유 옵션을 표시한다
10. **결과**: 사용자가 재미있는 결과를 얻고 친구들에게 공유하여 바이럴 확산

### 시나리오 2: 사진 재업로드 (마음에 들지 않는 사진)

1. 사용자가 사진을 업로드하고 미리보기를 확인한다
2. 사진이 흐릿하거나 각도가 마음에 들지 않는다
3. 사용자가 "다시 찍기" 또는 "다른 사진 선택" 버튼을 누른다
4. 시스템이 업로드 화면으로 돌아간다
5. 사용자가 새 사진을 업로드한다
6. 시스템이 새 사진 미리보기를 표시한다
7. 사용자가 만족하고 "분석 시작" 버튼을 누른다
8. **결과**: 사용자가 원하는 사진으로 정확한 분석을 받음

### 시나리오 3: 분석 실패 (AI API 오류)

1. 사용자가 사진을 업로드하고 "분석 시작" 버튼을 누른다
2. 시스템이 AI 분석을 시작한다
3. AI API가 일시적으로 응답하지 않거나 오류를 반환한다
4. 시스템이 에러 메시지를 표시한다
   - "아이고, 관상가 양반이 잠시 자리를 비웠사옵니다. 잠시 후 다시 시도해주시게."
5. 사용자가 "다시 시도" 버튼을 누른다
6. 시스템이 분석을 재시도한다
7. **결과**: 일시적 오류에도 사용자가 쉽게 재시도할 수 있음

### 시나리오 4: 이미지 생성 실패 (시뮬레이션만 실패)

1. 사용자가 분석을 완료하고 결과 화면을 확인한다
2. AI 분석 결과 카드는 정상적으로 표시된다
3. 10년 뒤 시뮬레이션 이미지 생성이 실패한다
4. 시스템이 이미지 영역에 플레이스홀더를 표시한다
   - "시뮬레이션 이미지를 준비할 수 없사옵니다"
5. 사용자는 분석 결과는 확인하고 공유할 수 있다
6. **결과**: 부분 실패 시에도 핵심 기능(분석)은 제공됨

### 시나리오 5: 모바일에서 카메라 직접 촬영

1. 사용자가 모바일 브라우저에서 탈모상 웹앱에 접속한다
2. 시스템이 업로드 영역을 표시한다
3. 사용자가 업로드 영역을 탭한다
4. 시스템이 파일 선택 대화상자를 표시한다 (카메라 옵션 포함)
5. 사용자가 "카메라로 촬영" 옵션을 선택한다
6. 브라우저가 카메라 권한을 요청한다
7. 사용자가 권한을 허용하고 셀카를 촬영한다
8. 시스템이 촬영된 사진 미리보기를 표시한다
9. 사용자가 "분석 시작" 버튼을 누른다
10. **결과**: 모바일에서도 끊김 없이 촬영 및 분석 가능

### 시나리오 6: 결과 공유 (Web Share API 미지원 브라우저)

1. 사용자가 분석 결과를 확인하고 "공유하기" 버튼을 누른다
2. 시스템이 브라우저의 Web Share API 지원 여부를 확인한다
3. Web Share API가 지원되지 않는 브라우저다 (예: 데스크톱 Chrome)
4. 시스템이 대체 공유 옵션을 표시한다
   - "결과 이미지 다운로드" 버튼
   - "링크 복사" 버튼
5. 사용자가 "링크 복사" 버튼을 누른다
6. 시스템이 클립보드에 링크를 복사하고 "복사되었습니다" 알림을 표시한다
7. 사용자가 메신저나 SNS에 직접 링크를 붙여넣는다
8. **결과**: 모든 브라우저에서 공유 가능

### 시나리오 7: 광고 노출 및 클릭

1. 사용자가 메인 화면에 접속한다
2. 시스템이 상단 또는 하단에 Google AdSense 광고를 표시한다
3. 사용자가 사진을 업로드하고 분석을 시작한다
4. 분석 중 로딩 화면에도 광고가 표시된다
5. 결과 화면 하단에도 광고가 표시된다
6. 사용자가 광고에 관심을 갖고 클릭한다
7. **결과**: 무료 서비스를 지속 가능하게 만드는 수익 발생

## 인수 조건 (Acceptance Criteria)

- [ ] 사용자가 드래그앤드롭 또는 클릭으로 사진을 업로드할 수 있다
- [ ] 모바일 브라우저에서 카메라를 통해 직접 촬영할 수 있다
- [ ] 업로드된 사진의 미리보기를 확인할 수 있다
- [ ] 사진이 마음에 들지 않으면 재업로드할 수 있다
- [ ] AI 분석 중에 사극 말투의 로딩 메시지가 5-10초마다 전환된다
- [ ] 분석 결과 카드에 모발 등급, 모발 나이, 탈모 확률, 탈모 유형, 닮은 유명인, 관리팁이 표시된다
- [ ] 10년 뒤 헤어라인 시뮬레이션 이미지가 생성되어 표시된다
- [ ] Web Share API 지원 브라우저에서 결과를 SNS에 공유할 수 있다
- [ ] Web Share API 미지원 브라우저에서 링크 복사 또는 이미지 다운로드로 공유할 수 있다
- [ ] AI 분석 실패 시 사용자 친화적인 에러 메시지가 표시되고 재시도할 수 있다
- [ ] 시뮬레이션 이미지 생성 실패 시에도 분석 결과는 표시된다
- [ ] Google AdSense 광고가 메인 화면, 로딩 화면, 결과 화면에 적절히 표시된다
- [ ] 모바일과 데스크톱에서 동일한 품질의 경험을 제공한다
- [ ] 메인 타이틀 "탈모상"과 메인 카피 "이보시오 관상가 양반, 내가 탈모가 될 상인가?"가 명확히 표시된다

## 엣지 케이스

- **지원하지 않는 파일 형식 업로드**: "지원하지 않는 파일 형식입니다. JPG, PNG 파일을 업로드해주시게." 에러 메시지 표시
- **파일 크기 초과 (10MB 이상)**: "파일 크기가 너무 크옵니다. 10MB 이하의 이미지를 올려주시게." 에러 메시지 표시
- **얼굴이 인식되지 않는 사진**: AI가 얼굴을 찾지 못하면 "얼굴을 찾을 수 없사옵니다. 정면 사진으로 다시 시도해주시게." 메시지 표시
- **동일한 사진 반복 업로드**: 중복 검사 없이 매번 새로운 분석 결과 제공 (일관성은 AI 모델에 의존)
- **AI API Rate Limit 초과**: "많은 사람들이 관상을 보고 있사옵니다. 잠시 후 다시 시도해주시게." 메시지 표시 및 재시도 유도
- **카메라 권한 거부**: "카메라 권한이 필요하옵니다. 브라우저 설정에서 권한을 허용해주시게." 안내 메시지 표시
- **네트워크 연결 끊김 (분석 중)**: "통신이 원활하지 않사옵니다. 네트워크 연결을 확인해주시게." 메시지 표시 및 재시도 버튼
- **광고 차단 도구 사용**: AdSense가 로드되지 않아도 핵심 기능은 정상 작동

## 비즈니스 규칙

- **분석은 1회성**: 결과 저장하지 않음, 매번 새로운 분석 수행
- **로그인 불필요**: 모든 기능을 익명으로 사용 가능
- **의료 진단 아님**: 결과 화면 하단에 "본 서비스는 재미 목적이며 의료 진단이 아닙니다" 면책 문구 표시
- **무료 서비스**: 광고 수익으로 운영, 별도 결제 없음
- **개인정보 수집 안 함**: 업로드된 사진은 분석 후 즉시 삭제, 서버에 저장하지 않음
- **AI 모델 선택**: Google Gemini API 무료 티어 사용 (분석: Gemini 2.5 Flash, 이미지 생성: Gemini 2.0 Flash Exp)
- **공유 링크 정책**: 결과 화면 URL은 고유하지만, 새로고침 시 데이터 소실 (서버 저장 안 함)

## 필요한 데이터

| 데이터 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| 업로드 이미지 | File (JPG/PNG) | ✅ | 사용자가 업로드한 얼굴 사진 (10MB 이하) |
| 모발 등급 | String | ✅ | AI 분석 결과: A-F 등급 |
| 모발 나이 | Number | ✅ | AI 분석 결과: 실제 나이 대비 모발 나이 (예: -5, +3) |
| 탈모 확률 | Number (%) | ✅ | AI 분석 결과: 0-100 사이 퍼센트 값 |
| 탈모 유형 | String | ✅ | AI 분석 결과: M자형, 정수리형, 전체형 등 |
| 닮은 유명인 | String | ✅ | AI 분석 결과: 유명인 이름 및 시기 |
| 관리팁 | Array<String> | ✅ | AI 분석 결과: 3-5개의 간단한 관리팁 |
| 시뮬레이션 이미지 | Image URL | ✅ | AI 생성 이미지: 10년 뒤 예상 헤어라인 |
| 로딩 메시지 목록 | Array<String> | ✅ | 사극 말투의 재미있는 로딩 메시지들 |
| 공유 URL | String | ❌ | 결과 공유용 URL (서버 저장 안 할 경우 불필요) |

## 비기능 요구사항

### 성능
- **분석 완료 시간**: 업로드 후 20-30초 이내에 결과 표시
- **이미지 업로드**: 10MB 이하 이미지 5초 이내 업로드 완료
- **페이지 로딩**: 첫 화면 2초 이내 렌더링
- **모바일 최적화**: 3G 네트워크에서도 사용 가능

### 접근성
- **반응형 디자인**: 모바일(320px 이상), 태블릿, 데스크톱 모두 지원
- **키보드 내비게이션**: 모든 버튼과 입력 영역 키보드로 접근 가능
- **대체 텍스트**: 모든 이미지에 적절한 alt 속성 제공
- **색상 대비**: WCAG 2.1 AA 기준 준수 (배경/텍스트 대비)

### 에러 처리
- **사용자 친화적 메시지**: 모든 에러 메시지를 사극 말투로 유머러스하게 표현
- **재시도 유도**: 에러 발생 시 명확한 "다시 시도" 버튼 제공
- **부분 실패 처리**: 이미지 생성 실패 시에도 분석 결과는 표시
- **에러 로깅**: 서버 로그에 AI API 오류 상세 기록 (사용자 이미지 제외)

### 보안
- **HTTPS 필수**: 모든 통신 암호화
- **파일 검증**: 업로드 파일의 MIME 타입 및 확장자 검증
- **Rate Limiting**: IP당 분당 5회 분석 제한 (API 남용 방지)
- **XSS 방지**: 사용자 입력(없음)에 대한 이스케이프 처리
- **CSP 설정**: Content Security Policy 헤더 설정 (광고 스크립트 허용)

### 배포
- **플랫폼**: Vercel
- **환경 변수**: Google Gemini API 키, AdSense Publisher ID
- **모니터링**: Vercel Analytics로 트래픽 및 오류 추적
- **버전 관리**: Git 브랜치 전략 (main: production, dev: staging)
